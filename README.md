# cardiadev/homebrew-tap

Homebrew formulae for [cardiadev](https://github.com/cardiadev) projects.

```sh
brew install cardiadev/tap/memo
```

## Formulae

| Formula | Description |
| --- | --- |
| [memo](https://github.com/cardiadev/memo) | Per-repository vector memory for AI coding agents |

`Formula/memo.rb` is generated automatically by the memo release workflow.
Do not edit it by hand — change the template in the
[memo repo](https://github.com/cardiadev/memo/blob/main/packaging/homebrew/memo.rb.template).
